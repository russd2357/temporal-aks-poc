This is the web frontend for the Temporal demo. It is built using [Next.js](https://nextjs.org/) and [Typescript](https://www.typescriptlang.org/). I used Next.js because it sits on top of React but is easiuer to develop with (my opinion - your mileage may vary).


## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
